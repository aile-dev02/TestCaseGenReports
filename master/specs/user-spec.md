## 2. テスト環境・データ

### 2.1 環境構成

- ブラウザ: Chrome 最新版（Windows 11）
- テスト環境 URL: https://staging.example.com

### 2.2 テストデータ準備方針

- ログイン済みの一般ユーザーアカウントを使用する
- テスト前にプロフィールを既知の初期値（氏名: "山田 太郎" / メール: "taro@example.com"）にリセットする

### 2.3 個人情報・機微データ取扱い

- テスト用ダミーデータのみ使用し、実個人情報は使用しない

### 2.4 外部システム連携

- メール送信機能はスタブを使用し、実メール送信は行わない

## 3. テストケース

| TC-ID | テスト名 | 種別 | 手順 | 期待結果 | 上流ID | 備考 |
|---|---|---|---|---|---|---|
| TC-005 | 正常系：プロフィール更新 | 画面 | 1. ヘッダーのユーザーアイコン→「プロフィール編集」を選択する 
2. 氏名を「山田 花子」に変更する 

3. メールアドレスを「hanako@example.com」に変更する 
4. 「保存」ボタンを押下する | 「プロフィールを更新しました」成功メッセージが表示される。変更した氏名・メールアドレスが画面に反映される。DBに更新日時が記録される。 | DD-002 | |
| TC-006 | 異常系：無効メールアドレスへの更新バリデーション | 画面 | 
1. プロフィール編集画面を開く 
2. メールアドレスフィールドに「not-an-email」を入力する 
3. 「保存」ボタンを押下する | 保存が拒否される。「有効なメールアドレスを入力してください」バリデーションエラーが表示される。DBへの更新は行われない。 | DD-002 | |

## 4. 結合・シナリオテスト

### 4.1 業務シナリオ

| シナリオ名 | 関連TC-ID | 概要 |

| プロフィール更新フロー | TC-005, TC-006 | 正常更新後に異常値を入力し、バリデーションが機能することを一連で検証する |

### 4.2 ユーザー権限・ロール組み合わせ

- 一般ユーザー: TC-005〜TC-006 対象

- 更新処理のレスポンスタイム 1秒以内
